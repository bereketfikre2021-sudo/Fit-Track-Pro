ICON SETUP INSTRUCTIONS
========================

You need to create two PNG icon files:

1. icon-192.png (192x192 pixels)
2. icon-512.png (512x512 pixels)

QUICK SOLUTION:
---------------
Use an online tool like:
- https://favicon.io/favicon-generator/
- https://realfavicongenerator.net/

DESIGN (current):
-----------------
- Background: Lime (#a3e635)
- Icon: Dark dumbbell (#0a0a0a)
- Generated by: npm run generate-icons

TEMPORARY SOLUTION:
------------------
For testing, you can use any 192x192 and 512x512 PNG images.
Just name them icon-192.png and icon-512.png and place them in the public folder.

The app will work without icons, but won't look professional when installed.
